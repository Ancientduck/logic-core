Dedicated Chrome Automation Profile Setup

Required for Selenium, Playwright, Messenger tools, and automated web interactions.

AutomationProfile

LOGIC operates with a dedicated persistent Chrome user profile located at:

C:\Users\<YOUR_USERNAME>\AppData\Local\Google\Chrome\AutomationProfile
1 Launch Automation Profile

Run via CMD or Run dialog (Win+R):

chrome.exe --user-data-dir="C:\Users\%USERNAME%\AppData\Local\Google\Chrome\AutomationProfile"
2 One-Time Account Logins

In that opened Chrome window, log in to Facebook/Messenger, Torn, and any active sites you want LOGIC to automate.

3 Automated Reconnection

LOGIC's Playwright and Selenium drivers will automatically mount this profile with saved sessions and zero CAPTCHAs.

Step-by-Step Acquisition Guides

Exact instructions to obtain all keys and configure local daemons.

1. Groq Cloud API Key

console.groq.com
  1. Sign in to console.groq.com.
  2. Navigate to API Keys in the left sidebar.
  3. Click Create API Key, name it logic-groq, and copy the key (gsk_...).
  4. Paste into your .env under GROQ_API_KEY.

2. OmniRoute AI Gateway

GitHub Repo
  1. Clone or install OmniRoute locally (or run open_omniroute.py).
  2. Ensure OmniRoute runs on port 20128 (http://127.0.0.1:20128).
  3. Configure your target providers at localhost:20128/home.
  4. Set BASE_URL=http://localhost:20128/v1 in .env.

3. Google OAuth (google_oauth.json)

Cloud Console
  1. Go to Google Cloud Console → APIs & Services → Credentials.
  2. Enable Google Calendar API and Gmail API.
  3. Click Create Credentials → OAuth client ID → Application type: Desktop App.
  4. Download JSON and save as: logic_tools/oauth_token_files/google_oauth.json
  5. Run get_schedule.py to complete the one-time browser login and create token.json.

4. GitHub PAT (github_access.json)

GitHub Settings
  1. Navigate to github.com/settings/tokens → Generate new token (classic).
  2. Select scopes: repo (Full repository control) and gist.
  3. Create file logic_tools/oauth_token_files/github_access.json containing: 
    {"token": "ghp_your_personal_access_token_here"}

5. Voidtools Everything HTTP Server

voidtools.com
  1. Install Everything on Windows.
  2. Open Everything → Tools → Options → HTTP Server.
  3. Check "Enable HTTP server" and set Port: 80 (leave Username/Password empty).
  4. Click Apply. find_file.py queries http://127.0.0.1:80/?search=... for sub-millisecond local file searches.

6. DeepWrap Vision Analyzer

Kuduxaaa/deepwrap
  1. Install the DeepWrap package from GitHub: 
    pip install git+https://github.com/Kuduxaaa/deepwrap.git
  2. Run the one-time interactive browser login in your terminal: 
    deepwrap auth
  3. Session credentials will be saved in ~/.deepwrap/ for automated visual processing with image_analyzer.py.
