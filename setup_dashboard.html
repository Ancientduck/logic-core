Complete Zero-Coding Setup Guide (Python, Node/NPM, OmniRoute, Everything)
Read This If Starting Fresh
1 Install Python (Required for Logic)
1. Go to python.org/downloads and download Python 3.11 or newer.
2. CRITICAL: When running the installer, check the box that says "Add python.exe to PATH" before clicking Install.
python --version
Run this in Command Prompt to confirm it's working.
2 Install Node.js & NPM
1. Go to nodejs.org and download the LTS (Recommended) version.
2. Run the downloaded installer. Keep clicking "Next" and finish installation. NPM comes bundled automatically.
node -v && npm -v
Run this in Command Prompt to verify Node and NPM.
3 Install & Start OmniRoute
Open Command Prompt (Press Win + R, type cmd, press Enter) and install OmniRoute globally via NPM:
npm install -g omniroute
Then launch it by typing:
omniroute start
It will open at http://localhost:20128.
4 Install Everything Search (for find_file)
1. Download Voidtools Everything from voidtools.com.
2. Open Everything → Click Tools → Options → HTTP Server.
3. Check "Enable HTTP server" (Default port 80). Click Apply.

⭐ RECOMMENDED QUICKSTART: Google AI Studio (Free, High Intelligence)
  1. Go to Google AI Studio and create your free Gemini API key in 30 seconds.
  2. Open your OmniRoute console at localhost:20128 → Providers → Add Google AI Studio and paste your API key.
  3. Go to Models in OmniRoute, locate or copy the Gemini model alias (e.g., gemini-2.5-flash or gemini-2.5-flash-lite), and paste it into the MODEL field above.
  4. Go to API Tokens in OmniRoute, create a token, and paste it into API_KEY above.
💡 Once LOGIC boots on your machine with Gemini Flash, you can speak directly to LOGIC to guide you through setting up advanced custom model combos, OpenRouter, or Anthropic.
